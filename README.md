# InsureHub

Информационный портал о страховании: автострахование, ипотека, путешествия, имущество. / An information portal about car, mortgage, travel and property insurance.

**Сайт / Site:** https://insure-hub.ru/ · **YouTube:** https://www.youtube.com/@Insure-hub

> В этом репозитории только описание проекта. Исходный код закрыт. / This repository contains the project description only; the source code is private.

## Что внутри / What it is

- 114 страниц, 61 статья в журнале, 11 страховых компаний. / 114 pages, 61 journal articles, 11 insurance companies.
- Статический сайт: страницы собирает Python-генератор из структурированных данных, новый раздел или статья появляются за минуты.
- Разделы: справочник, журнал, рейтинги компаний, направления страхования, партнёрские договоры. Серверный API принимает формы и заявки.
- Для поисковиков и ИИ: sitemap, search.json, llms.txt, ai-catalog.json, разметка Schema.org.

## Стек / Stack

Python · HTML/CSS/JS · REST API · SEO · Schema.org
